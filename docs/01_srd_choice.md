# Шаг 1. Правила: SRD 5.1 или SRD 5.2.1

**Решение (2026-11-23):** работаем на SRD 5.1. Если понадобится, позже переходим на 5.2.1.
Следствие: правила и контент держим отдельным слоем, чтобы редакцию можно было заменить.

Источники: `SRD_CC_v5.1.pdf` (правила 2014 г., «5e») и `SRD_CC_v5.2.1.pdf` (правила 2024 г., «5.5e»).
Оба под CC-BY-4.0: лицензия одинаковая, нужна только строка атрибуции.

## Содержимое

| | SRD 5.1 | SRD 5.2.1 |
|---|---|---|
| Страниц | 403 | 364 |
| Классы | 12, по одному подклассу | 12, те же подклассы |
| Расы / виды | 9 (есть Half-Elf, Half-Orc) | 9 (вместо них Goliath, Orc) |
| Предыстории | 1 | 4, каждая даёт черту |
| Черты | 1 (Grappler) | 17 |
| Заклинания | 319 (24 заговора) | 339 (27 заговоров) |
| Статблоки | ≈317 | ≈327 |
| Глоссарий правил | нет | есть, 16 страниц |

## Что меняется в бою

| Правило | SRD 5.1 | SRD 5.2.1 |
|---|---|---|
| Внезапность | пропуск первого хода | помеха на инициативу |
| Заклинания за ход | после бонусного — только заговор | одна ячейка за ход |
| Захват, толчок | состязание Атлетики | спасбросок против DC 8 + Сил + БМ |
| Истощение | 6 уровней с разными эффектами | −2 к d20 и −5 фт скорости за уровень |
| Мастерство оружия | нет | 8 свойств (Cleave, Graze, Nick, Push, Sap, Slow, Topple, Vex) |
| Прятаться | состязание проверок | DC 15, даёт Invisible |
| Статблок | инициатива не указана | указаны инициатива и спасброски |

Монстры с одинаковым именем тоже отличаются. Пример — Owlbear:
- **5.1:** клюв и когти, Perception +3.
- **5.2.1:** две атаки Rend, Perception +5, есть Climb.

Гуманоиды в 5.2.1 переименованы и разделены: Goblin → Goblin Minion / Warrior / Boss, Kobold → Kobold Warrior.

## За и против

**SRD 5.1**
- \+ FIREBALL записан на этих правилах (Avrae, 2022).
- \+ Модель оценки ситуации и данные будут про одни и те же правила.
- \+ Имена монстров в логах совпадают со статблоками.
- − Старая редакция; новые игроки чаще знают 2024.
- − Правила менее формальны, больше трактовок.

**SRD 5.2.1**
- \+ Актуальная редакция.
- \+ Глоссарий и единый формат статблоков проще перевести в код.
- \+ Мастерство оружия даёт воинам больше тактики.
- − Расхождение с FIREBALL: данные про 2014, бои про 2024.
- − Статблоки из логов не совпадают с SRD.

## Рекомендация

**SRD 5.1.** Проект опирается на FIREBALL. Модель оценки ситуации нужно проверять на реальных боях. Это возможно, только если правила совпадают.

Выбирать 5.2.1 стоит, если важнее актуальность и тестеры играют по 2024. Тогда FIREBALL — только приближённый источник.
